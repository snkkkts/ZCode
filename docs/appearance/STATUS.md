# 主题系统阶段交接基线

整理日期：2026-09-22。分支：`feat/appearance-system`。本文件随第一份主题系统 Git 提交归档；提交号以 Git 历史为准，避免在提交内容中嵌入自身哈希。

## 已实现

- 背景图、填充方式、模糊、遮罩；主面板和侧栏透明度。
- 界面与代码字体；浅深色独立的 14 类颜色；公式颜色、字重与字号。
- 实时 JSON 编辑、按字段合并、保留未修改背景、完整配置复制导出、保存失败保护、恢复默认。
- 中英文设置、跨窗口广播接收与回环保护。
- Preview 窗口标题、开发数据入口、Windows 桌面快捷方式与启动复用。
- [7 套配置示例](presets/README.md)已纳入版本控制。

## 验证边界

- 配置与公式相关 14 个单元场景；真实组件预览页上的两组 E2E；仓库类型、lint、架构与格式检查。
- E2E 使用正式组件与 store，但广播传输为测试替身，不等于完整桌面 RPC 多窗口验收。
- 已验证完整开发应用启动和桌面快捷方式复用；未完成所有登录后业务页面的外观覆盖检查，也未构建发行安装包。
- 逐轮检查结果、历史故障和处理见 [CHANGELOG.md](CHANGELOG.md)；历史条目的“未提交”等描述是当时状态，不代表本基线仍未归档。

## 下一阶段优先项

1. 在真实聊天、代码预览、Diff、终端、菜单和弹窗中建立覆盖矩阵，检查浅深色、重启、缩放及字体回退。
2. 聊天正文独立字体、字号和行距；更多颜色与交互状态。
3. 软件内主题方案命名、保存、复制、切换，以及更完整的偏好迁移。
4. 再评估背景位置、更多区域透明度、窗口透出桌面与发行验证。

“高度可定制”尚未整体验收：当前是可用的基础系统及部分精细定制，不把已声明变量等同于每个业务页面都已验证。

## 接手入口

先阅读仓库 `AGENTS.md`，再阅读 [GOALS.md](GOALS.md)、[DEVELOPMENT.md](DEVELOPMENT.md) 与当前功能 spec。新增行为先更新 spec，变更后同步记录。当前 JSON 规则以 [CONFIGURATION.md](CONFIGURATION.md) 和 [transfer.spec.md](transfer.spec.md) 为准。
